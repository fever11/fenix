# Установка FENIX (Русский)

Займёт около **15 минут**. Специальные знания не нужны — просто выполняйте шаги по порядку.

## Что понадобится

| | |
|---|---|
| Компьютер | Windows 10 или 11 |
| Программа | Python 3.12 (бесплатно) |
| Ключ | Ключ Gemini API (бесплатно, обязательно) |
| По желанию | Ключ Groq API (бесплатно; быстрее чат и лучше распознавание речи) |
| По желанию | Ключ NVIDIA API (бесплатно; резервный чат, когда лимит Groq исчерпан) — https://build.nvidia.com |

## 1. Скачайте FENIX

1. На странице GitHub нажмите зелёную кнопку **Code** → **Download ZIP**.
2. Щёлкните ZIP правой кнопкой → **Извлечь всё**. Положите папку в простое место, например `Документы\fenix`.

## 2. Установите Python

1. Скачайте **Python 3.12** с https://www.python.org/downloads/.
2. На первом экране установщика **обязательно отметьте "Add python.exe to PATH"**, затем **Install Now**.

## 3. Получите ключ Gemini

1. Откройте https://aistudio.google.com/apikey и войдите в аккаунт Google.
2. **Create API key** → скопируйте ключ. **Никому его не показывайте**.
3. (По желанию) Ключ Groq можно получить на https://console.groq.com/keys.

## 4. Запустите установку

1. Дважды щёлкните **`Setup.bat`** в папке FENIX.
   - Если появится «Система Windows защитила ваш компьютер»: **Подробнее → Выполнить в любом случае**.
2. Выберите язык в окне (1-6).
3. Если Python не установлен, установщик сообщит об этом и предложит установить его автоматически.
4. Подождите, пока установятся пакеты (5-10 минут). На рабочем столе появится ярлык **FENIX**.

## 5. Запустите FENIX и вставьте ключ

- Дважды щёлкните значок **FENIX** на рабочем столе.
- При первом запуске появится небольшое окно **API-ключ**: вставьте ключ Gemini (и Groq, если есть) и нажмите **Сохранить и запустить**. Редактировать файлы не нужно.
- Язык можно сменить позже в **⚙️ Настройках**.

## Кратко об использовании

| Что | Как |
|---|---|
| Текстовый чат | Пишите внизу, **Enter** |
| Голосовой чат | Кнопка **🎤 Нажми и говори** или **F9** |
| Прикрепить файл / картинку | **📎**, перетаскивание или **Ctrl+V** |
| Режим | **Безопасный** (только чат) · **Normal** (повседневные дела, спрашивает о рискованных) · **Devil** (глубокое исследование, отчёты) |
| Аварийная остановка | **Ctrl+Alt+Q** или задержите мышь в левом верхнем углу на 1,5 с |

Перед рискованными действиями (удаление, выключение, загрузка и т. п.) FENIX **в любом режиме спрашивает подтверждение**.

## Проблемы?

| Симптом | Решение |
|---|---|
| «Python не найден» | Переустановите Python и отметьте **Add python.exe to PATH**. |
| Ошибка ключа / нет ответов | Запустите **`Connection_Test.bat`** — покажет, какой ключ не работает. |
| Микрофон не слышит | Запустите **`Microphone_Test.bat`**. Выберите нужный микрофон в настройках звука Windows. |
| Окно не открывается | Запустите **`Start_FENIX_Debug.bat`** — сообщение об ошибке останется на экране. |
| Не работает дежурство | Работает только в Windows; запустите `Setup.bat` ещё раз. |

Примечание: вспомогательные тестовые скрипты выводят сообщения на турецком.

## Безопасность

- В `config.yaml` хранятся ваши ключи: **никому не отправляйте и не загружайте на GitHub.**
- В папке `data` — ваши чаты и память; это тоже личное.
- Если ключ где-то засветился, **удалите его на сайте сервиса и создайте новый**.
