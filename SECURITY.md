# Security / Güvenlik

## Reporting / Bildirme

If you find a security problem, **don't open a public issue**. Use GitHub's **"Report a vulnerability"** button
(Security tab) so that only the author can see it.
Bir güvenlik açığı bulursan **herkese açık issue açma**. Sadece yazarın görebilmesi için GitHub'daki **"Report a
vulnerability"** düğmesini (Security sekmesi) kullan.

## Built-in safeguards / Yerleşik önlemler

- Risky actions (delete, shut down, end process, change startup, overwrite files, erase memory) ask for approval in every
  mode. / Riskli işlemler her modda onay ister.
- Safe mode never touches the system. / Güvenli mod sisteme hiç dokunmaz.
- Deleted files go to the Recycle Bin. / Silinen dosyalar Geri Dönüşüm Kutusu'na gider.
- FENIX can turn Defender and the firewall on, never off. / FENIX Defender'ı ve güvenlik duvarını açabilir, kapatamaz.
- Kill switch: Ctrl+Alt+Q or hold the mouse in the top-left corner. / Acil durdurma: Ctrl+Alt+Q ya da fareyi sol üst köşede tut.

## Be careful / Dikkat

FENIX is an AI agent. Web pages and files it reads may contain hidden instructions. Read every approval box before
clicking "Approve", and use **Safe mode** when working with content you don't trust.
FENIX bir yapay zekâ ajanıdır. Okuduğu web sayfaları ve dosyalar gizli talimatlar içerebilir. "Onayla"ya basmadan önce
her onay kutusunu oku; güvenmediğin içerikle çalışırken **Güvenli mod** kullan.

## Official source / Resmi kaynak

Only download FENIX from the author's official repository and compare the release's SHA-256 fingerprint.
FENIX'i yalnızca yazarın resmi deposundan indir ve sürümün SHA-256 parmak izini karşılaştır.
